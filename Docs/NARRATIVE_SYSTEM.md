# Omnis — Narrative System

## Narrative model

Narrative progression is represented as state and consequences rather than a single immutable quest chain.

## Decisions

Decisions can modify character relationships, faction reputation, mission availability and future world state.

## Characters

Major characters have persistent state across the current run and, when explicitly designed for it, consequences that survive the end of a cycle.

## Cinematics

Cinematic presentation remains a presentation layer over authoritative narrative state. A cinematic must never become the sole source of truth for a gameplay consequence.
