# Omnis Localization

Spanish (es) is the native source culture. Runtime culture changes are handled by UOmnisLocalizationSubsystem.

The localization target is generated from Unreal's normal localization pipeline. Final translated dialogue and UI assets must be created from authored game text and reviewed by language QA; this file does not claim translation completeness.

Supported runtime cultures are declared in Config/DefaultGame.ini and generated cultures in Config/Localization/OmnisGame.ini.
