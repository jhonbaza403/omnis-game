# Omnis Unity Assets

Esta carpeta está reservada para assets propios del vertical slice de Omnis.

## Estado actual

No se deben dar por existentes modelos, animaciones, materiales, sonidos o escenas solo porque la carpeta esté creada. Añade aquí recursos reales y revisa su licencia antes de incluirlos en una build.

## Reglas

- Mantener nombres estables y referencias comprobables.
- No introducir assets descargados sin registrar procedencia y licencia.
- Evitar archivos placeholder como `.gitkeep`; esta documentación mantiene visible el propósito de la carpeta.
- Los recursos de gameplay deben tener pruebas o una escena de verificación cuando corresponda.
