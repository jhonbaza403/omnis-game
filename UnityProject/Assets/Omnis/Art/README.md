# Omnis Unity vertical-slice art

The Unity vertical slice creates its initial environment deterministically from source code: basalt causeway, layered Nexus dais, faceted memory crystals, fractured stone arches, canopy clusters, aether pools, fog, emissive materials, motes, and a URP post-processing baseline.

This is executable procedural art, not a claim that the project's separate Git LFS placeholder files are imported into Unity. The OBJ files under the repository-root Content/Omnis/SourceAssets were checked and several are LFS pointer stubs in the remote repository view. They must be pulled/materialized and inspected before being treated as valid production models.

Target baseline: Unity 6000.3.0f1 + URP 17.3.0, linear color space, 3840x2160 standalone default, 4x MSAA, HDR, Forward+, 4096 main-light shadow map. A 4K output mode does not guarantee production-quality art or a stable frame rate on every device; acceptance requires a real Windows build and measured playtest on the intended GPU.
