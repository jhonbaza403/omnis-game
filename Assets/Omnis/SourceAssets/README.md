# Source asset import boundary

The repository's verified source assets live under:

`Content/Omnis/SourceAssets/`

Import/copy the original files into this Unity area only through a real Unity import workflow. Do not rename Unreal binaries and do not generate placeholder geometry.

Expected source categories include:

- Animals
- Architecture
- Aviation
- Characters
- Infrastructure
- Interiors
- Nature
- Obelisk
- Textures
- Tools
- Vehicles

The existing Git LFS objects must remain the source of truth for binary source assets.
